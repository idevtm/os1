01 / The idea

A system that shows its work.

From a device on the bus to a service in the shell, OS1 aims to make the relationships inside a computer visible and understandable.

01

Discover

Find devices, processes, and services through consistent system objects.

02

Understand

Inspect capabilities, events, and failures with evidence that helps explain what happened.

03

Control

Give programs explicit access to the resources they need, and make that authority visible.

02 / One foundation

From small devices to the desktop.

One set of concepts, adapted to the job. These configurations describe a future direction, not finished products.

Core

Learn and explore.

A small system with a shell for development and diagnostics.

Desktop

See the system.

A graphical interface that makes devices, services, and their relationships easier to explore.

Embedded

Fit the device.

A tailored configuration with the services and diagnostics the device needs.
